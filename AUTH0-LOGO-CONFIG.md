# 🖼️ Configuration du Logo dans Auth0

## Application Logo URL

Dans Auth0 Dashboard > Applications > "Garden Gold Green" > Settings > Application Logo

**Mettez cette URL :**

```
https://gardengoldgreen.com/logo.png
```

ou

```
https://gardengoldgreen.com/logo2.png
```

## Recommandations

- **Taille recommandée** : 150x150 pixels (comme indiqué dans Auth0)
- **Format** : PNG ou SVG
- **URL complète** : Utilisez l'URL complète avec `https://gardengoldgreen.com/`

## Vérification

Après avoir sauvegardé, le logo devrait apparaître :
- Dans l'écran de connexion Auth0
- Dans les emails Auth0
- Dans le dashboard Auth0

## Alternative

Si vous préférez utiliser un logo hébergé ailleurs, vous pouvez aussi utiliser :
- Un CDN (Cloudinary, Imgur, etc.)
- Un service d'hébergement d'images

Mais l'URL locale `https://gardengoldgreen.com/logo.png` est la solution la plus simple et recommandée.
